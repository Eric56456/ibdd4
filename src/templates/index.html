👤 Запрос для роли Зрителя: Сводка афиши и доступности билетов

Concert + Artist + Venue + Ticket (4 сущности)
SELECT c.concert_id, c.program_name, c.start_datetime, a.stage_name, a.music_genre, v.venue_name, v.city, COUNT(t.ticket_id) AS available_tickets, MIN(t.price) AS min_price, MAX(t.price) AS max_price, ROUND(AVG(t.price), 2) AS avg_price FROM concert c JOIN artist a ON c.artist_id = a.artist_id JOIN venue v ON c.venue_id = v.venue_id LEFT JOIN ticket t ON c.concert_id = t.concert_id AND t.ticket_status = 'Доступен' GROUP BY c.concert_id, c.program_name, c.start_datetime, c.age_restriction, a.stage_name, a.music_genre, v.venue_name, v.city ORDER BY start_datetime ASC;

🏢 Запрос для роли Персонала: Мониторинг сборов и заполняемости площадок

Concert + Promoter + Artist + Venue + Ticket (5 сущностей)
SELECT p.company_name, c.concert_id, c.program_name, a.stage_name, v.venue_name, v.total_capacity, COUNT(CASE WHEN t.ticket_status = 'Продан' THEN 1 END) AS tickets_sold, ROUND((COUNT(CASE WHEN t.ticket_status = 'Продан' THEN 1 END)::numeric / NULLIF(v.total_capacity, 0)) * 100, 2) AS occupancy_percent, COALESCE(SUM(CASE WHEN t.ticket_status = 'Продан' THEN t.price ELSE 0 END), 0) AS total_revenue, ROUND(AVG(CASE WHEN t.ticket_status = 'Продан' THEN t.price ELSE NULL END), 2) AS avg_sold_price FROM concert c JOIN promoter p ON c.promoter_id = p.promoter_id JOIN artist a ON c.artist_id = a.artist_id JOIN venue v ON c.venue_id = v.venue_id LEFT JOIN ticket t ON c.concert_id = t.concert_id GROUP BY p.company_name, c.concert_id, c.program_name, c.start_datetime, a.stage_name, v.venue_name, v.total_capacity ORDER BY total_revenue DESC;

🛡️ Запрос для роли Администратора: Коммерческая статистика артистов и география туров

Artist + Concert + Venue + Ticket (4 сущности)
SELECT a.artist_id, a.stage_name, a.music_genre, COUNT(DISTINCT c.concert_id) AS total_concerts, COUNT(DISTINCT v.city) AS cities_visited, COUNT(CASE WHEN t.ticket_status = 'Продан' THEN 1 END) AS total_tickets_sold, COALESCE(SUM(CASE WHEN t.ticket_status = 'Продан' THEN t.price ELSE 0 END), 0) AS total_gross, ROUND(COALESCE(SUM(CASE WHEN t.ticket_status = 'Продан' THEN t.price ELSE 0 END), 0) / NULLIF(COUNT(DISTINCT c.concert_id), 0), 2) AS avg_revenue_per_concert FROM artist a LEFT JOIN concert c ON a.artist_id = c.artist_id LEFT JOIN venue v ON c.venue_id = v.venue_id LEFT JOIN ticket t ON c.concert_id = t.concert_id GROUP BY a.artist_id, a.stage_name, a.music_genre ORDER BY total_gross DESC;
